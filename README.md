# Конструктор форм для откликов студентов

Сервис, где менеджер собирает форму в браузере, публикует ссылку и смотрит ответы
вместе с аналитикой того, на каком поле студенты бросают форму.

## Запуск

Нужен Node.js 20+.

    npm install
    npm start

Админка: http://localhost:3000/admin. Порт задаётся переменной `PORT`.
Тесты: `npm test`.

## Что умеет

- Конструктор: 7 типов полей, обязательность, порядок, публикация по случайной ссылке.
- Публичная форма с серверной валидацией, автосохранением черновика и прогресс-баром.
- Ответы в таблице и экспорт в CSV (с защитой от формул в ячейках).
- Аналитика: воронка «открыли → начали → отправили», поле, на котором чаще всего бросают,
  ошибки валидации по полям.

## Решения

- **Версии форм.** Каждая публикация создаёт неизменяемый снимок схемы, ответ привязан к версии.
  Правка опубликованной формы не ломает старые ответы.
- **Хранилище:** SQLite (better-sqlite3), файл `data/app.db` создаётся автоматически.
- **Фронтенд** на чистом JS без сборки, чтобы `npm start` работал сразу.
- **Защита:** серверная валидация, ограничение частоты запросов, honeypot от ботов,
  экранирование вывода, CSP.

## Сознательно не сделано

- Авторизация админки (по условию задания), в продукте нужна в первую очередь.
- Разбивка формы на шаги, условная логика, загрузка файлов.
- Отрицательные числа в CSV получают апостроф в начале: побочный эффект защиты от формул.
- «Место отказа» определяется по последнему полю, в которое зашёл человек.
